### 수정 요소

- 클릭 가능한 모든 요소 커서 포인터 설정
- 주 컬러인 민트 색상을 적절히 여러 가지로 설정(disabled, focus, hover, default 등)
  - 현재 민트 색상이 초록색에 가까워서 민트 색상에 부합하지 않음
- 삭제 버튼 같은 빨간색 색상도 기본 빨간색 말고 현재 컬러 계열과 어울리는 채도와 명도의 빨간색으로 변경
- 아이콘 두께가 너무 굵음
- 전체적인 디자인 레이아웃
  - 부드럽고, 통통 튀는 스타일
  - 현재는 기본에 충실한 사무적인 느낌이 강함
  - 폰트도 둥글둥글한 것으로 변형
- 이모티콘 적절히 활용하기(👕👖👗👟 등)
- 아이템 선택 시, 모바일 뷰포트 벗어남
  - 카드 형식보다는 작은 목록 형식으로 변경
